# RecruitTech – WordPress Recruitment Plugin

RecruitTech is a custom WordPress recruitment management plugin designed to connect companies with job seekers and manage the recruitment workflow through dedicated dashboards and role-based access control.

## 🚀 Features

### Authentication & User Management
- User registration and login
- Role-based access control
- Company and Job Seeker workflows
- Protected pages based on user role

### Company Features
- Company dashboard
- Company profile management
- Create job postings
- Edit existing jobs
- Delete jobs
- View company jobs
- Job status management
- Job deadline validation

### Job Management
- Job title and category
- Job type
- Experience level
- Required skills
- Salary
- Location
- Job description
- Requirements
- Benefits
- Application deadline
- Draft / Published / Closed / Deleted statuses
- Owner-based edit and delete permissions

### Database
- Custom WordPress database tables
- Database migration and column validation
- Safe table creation using WordPress database APIs
- Automatic handling of missing database columns

### UI & Templates
- Reusable WordPress templates
- Company dashboard
- Job seeker dashboard
- Registration and login forms
- Responsive Bootstrap-based interface
- Reusable navigation and footer components

## 🛠️ Technologies

- PHP
- WordPress
- MySQL
- WordPress Database API
- WordPress Shortcodes
- HTML
- CSS
- Bootstrap
- JavaScript

## 🔐 Security

The plugin includes WordPress security practices such as:

- Nonce verification
- Input sanitization
- Role-based access control
- Ownership validation
- Protected company/job management pages
